# Case 04 — 部署进程生命周期 E2E（无控制面）

**目的**：在**真实部署的 axond 进程**上验证治理生命周期，而不依赖控制面/签名包。
**跑法**：`go test ./cmd/axond -run TestGovernanceProcessLifecycleE2E`

## 期望与观测（核心，本会话复跑）

| 步骤 | 期望 |
| --- | --- |
| step-01..05 | 安装 A → 禁用（重启后仍禁用）→ 启用 → 检查候选 B（能力扩张需审批） |
| step-06..08 | 更新待审批时 A 仍服务；拒绝则丢弃 B；重试批准后 **B 活跃、A 成为回滚目标**（journal `previous` 指向 A） |
| step-09..10 | 不健康的 C 不激活（B 继续服务）；隔离 B |
| step-11..12 | 启用**不解除**隔离；`quarantine_release` 批准后才可重新激活 |
| step-13 | 卸载后重启**不复活** |

## 要点（契约）

- 部署进程 E2E 覆盖的是"**受治理动作的真实效果**"（安装/禁用/启用/更新/审批/隔离/卸载/重启），
  它不需要 SYNDOVELA；需要控制面的是"从注册表安装已签名包"那条路。
- 重启后的状态是**重新挣来的**：持久化的"期望"由上层策略重新施加，运行时不会凭记录声称存活。

## 判据

`PASS` 表示上述步骤在真实进程上全部成立；`-short` 时该套件被跳过（跳过即未验证，需明示）。
