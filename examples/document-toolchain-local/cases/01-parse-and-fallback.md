# Case 01 — 解析与降级

**跑法**：`go test ./internal/parser -run Test`（模块 `packages/janus-gateway`）

| 检查 | 期望 |
| --- | --- |
| 缺文件 / 无扩展名 | **拒绝**（不猜测格式） |
| txt / docx 回退路径 | 可用路径返回内容；docx 走回退并剥离 XHTML |
| pandoc 不存在 | **显式标记不可用**（不崩溃、不假装成功） |
| Markdown / LaTeX | 内容保真（不被误处理） |
| 解析链配置 | 自定义顺序生效；空顺序回落默认 |

**要点**：外部工具缺失是**可表达的状态**，不是异常路径——可用性判定必须能被上层查询。
