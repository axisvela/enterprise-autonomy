# Case 02 — 角色与作用域

**目的**：角色判定与作用域判定**正交**：角色足够不代表跨租户可见；越界必须表现为"不存在"。
**跑法**：`go test ./internal/bridge -run 'Role|Scope|Tenant'`、`go test ./internal/identity`

| 检查 | 期望 | 观测（2026-10-16） |
| --- | --- | --- |
| 角色层级 | `admin > member`；空角色/未知角色一律拒绝 | ✅ `roleAtLeast` 对未知 `min` 返回 false |
| 跨租户读取/写入 | `404`（不泄露存在性） | ✅ scope/tenant 套件 |
| 工作区作用域过滤 | 只返回本租户/工作区资源 | ✅ `*_scope_test.go` |
| 令牌服务 | 签发/校验/过期语义正确 | ✅ `internal/identity` |

**要点**：`403` 表达"角色不够"，`404` 表达"不是你的世界"；两者不得互相代替——
用 `403` 表达越界会泄露资源存在性，用 `404` 表达角色不足会掩盖配置错误。
