# Case 03 — 远程监听拒绝启动

**目的**：把 API 暴露到网络且**没有任何操作员凭证**时，运行时必须**拒绝启动**，而不是给匿名访问。
**跑法**：`go test ./internal/bridge -run TestValidateExposure`

| 场景 | 期望 | 观测（2026-10-16，核心 `2111418`） |
| --- | --- | --- |
| 回环、无凭证 | 允许（本地优先默认） | ✅ |
| 远程 + API key | 允许 | ✅ |
| 远程 + 令牌存储 | 允许 | ✅ |
| **远程 + 无任何凭证** | **报错并拒绝启动** | ✅ 错误信息指明需配置操作员认证 |

**要点**：这是"缺失即拒绝"的启动期守卫：错误发生在**监听之前**，因此不存在"先接受请求、再补救"的窗口。
`AXON_ALLOW_REMOTE` 只改变绑定地址，不改变这个前提。
