# Tekmovela — Engineering Assurance

## Public Role

Agent-engineering assurance platform for reproducible testing, diagnosis, release gating, and re-verification.

## Local Surface

| Item | Detail |
| --- | --- |
| Binaries | `tek` (local `tek.exe`) |
| Current port | none (CLI only) |
| Planned port | `1916` reserved |
| Database | PostgreSQL for migrations; local file store default |
| Interfaces | CLI only (`verify`, `harness`, `test`, `explain`, `gate`, `attest`, `coverage`, `reverify`, `migrate`) |
| Health | none |
