# Ecosystem Glossary

Common terms used across AxisRobo Enterprise Autonomy public material.

| Term | Meaning |
| --- | --- |
| Capability | A governed, invocable unit of function published, discovered, and audited through Moduregis. |
| Contract | A published interface and behavioral agreement between products; authoritative copies live in the private repository. |
| Control plane | The product surface that governs lifecycle, authorization, and audit for a domain. |
| Effect ledger | A deny-by-default record of agent-performed actions and their consequences in Praxovela. |
| Evidence | An auditable record of an observation, decision, or action used to support a claim or outcome. |
| Human decision gate | A required human review or approval before an autonomous action may continue. |
| Plan | A revisable, verified sequence of capability invocations produced by Orchadyn. |
| Process instance | A durable, recoverable instance of a workflow in Rheovela. |
| Reference adapter | A local, illustrative integration for examples; not a production system. |
| Reference stack | A product-composition overview for a class of outcomes. |
| Vertical slice | An end-to-end use case spanning multiple products toward a measurable outcome. |
| World model | A bitemporal, evidence-bearing operational state representation in Ontovela. |
| Workspace | A human-authority surface in Symbivela for goals, plan review, approvals, and evidence. |
